# sdlc/registry/

Global artifact index. `index.md` is regenerated by `/sync-registry` — do not edit manually. Changes will be overwritten on the next run.

## index.md structure

```markdown
# SDLC Registry

## Foundation Documents

| ID | Type | Status | Title |
|---|---|---|---|
| ARCH | architecture | approved | ... |

## Thread Artifacts

| ID | Type | Status | Title |
|---|---|---|---|
| SPEC-0001 | spec | approved | ... |
| ... | | | |

## Bug Artifacts

| ID | Severity | Priority | Status | Title |
|---|---|---|---|---|
| BUG-0001 | High | P1 | accepted | ... |
```

Run `/sync-registry` after major status transitions to keep the index current. The index is also regenerated by FEATURE-NNNN dashboards in `sdlc/features/`.
